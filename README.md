# Aayan Madnas — 3D Developer Portfolio

A modern, immersive 3D personal portfolio showcasing my skills, projects, and journey as a Software Engineering student and web developer. Built with a focus on interactive 3D visuals, cinematic scroll animations, smooth transitions, responsive design, and a recruiter-friendly user experience.

### ✨ Key Features

* Interactive 3D hero section and visual effects
* Smooth scrolling and scroll-triggered animations
* Animated project cards with interactive hover effects
* Dedicated sections for skills, education, and projects
* Contact information with GitHub and LinkedIn integration
* Responsive design for desktop, tablet, and mobile
* Performance optimization, accessibility, and secure development practices

### 🛠️ Technologies

React, JavaScript, HTML5, CSS3, Three.js, GSAP, Git, and GitHub, depending on the final implementation.
